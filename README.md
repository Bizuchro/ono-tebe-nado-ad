# Оно тебе надо

Учебная вёрстка страницы аукциона по макету Яндекс Практикума.

## Запуск

Откройте файл `index.html` в браузере. Сервер и установка зависимостей не нужны.

## Состав

- `index.html` — разметка страницы;
- `styles/` — глобальные и основные стили;
- `fonts/` — файлы шрифта Raleway;
- `images/` — изображения и логотипы;
- `.github/workflows/` — конфигурация тестов из заготовки Практикума.

Сайт представляет собой учебный статичный макет: кнопка ставки и ссылки на лоты не подключены к системе аукциона.

Перед сдачей добавьте в этот файл ссылку на свой репозиторий GitHub, как требует инструкция Практикума.
